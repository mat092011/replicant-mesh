# Replicant Mesh experiment archive

The dated reports and compact machine-readable summaries in this directory record
actual experiments and publication checks. Runs through 2026-10-17 predate the
rename to Replicant Mesh. Original image names, source paths, fingerprints and
measurement values are retained so those records can be traced to their source
commits. Their JSON and source-freeze records have not been rebranded.

Use the [migration guide](../RENAMING.md) for the old-to-new name mapping and the
[current lab guide](../PYTORCH_LAB.md) for executable commands. Historical results
do not validate a newly built image or establish new performance claims.
